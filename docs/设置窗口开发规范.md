# Bee 关键词回复设置窗口开发规范

## 当前实现

设置窗口运行在独立 Go Worker 中，由 `settings.go` 使用标准 Win32 子控件实现；规则转换和持久化操作由 `settings_model.go` 的 `SettingsController` 负责。窗口不进入 Bee C 壳 DLL，也不直接修改 JSON。

客户区基准尺寸为 980×640（96 DPI），按系统 DPI 等比缩放。窗口固定尺寸、首次居中、始终置顶，保留标题栏、系统菜单和最小化按钮。

## 控件布局

- 左侧：规则 `LISTBOX`，以及“新增”“删除”“上移”“下移”按钮。
- 右侧：关键词 `EDIT`、匹配模式 `COMBOBOX`、大小写敏感复选框。
- 区域：QQ 好友、群聊、频道消息、频道私信四个复选框。
- 回复：回复类型 `COMBOBOX` 和支持换行的内容 `EDIT`。
- 底部：“保存规则”按钮和状态 `STATIC`。

控件按创建顺序建立稳定 Tab 顺序。消息循环调用 `IsDialogMessageW`，多行回复框使用 `ES_WANTRETURN`。

## 编辑行为

- 列表摘要格式为“关键词｜匹配模式｜回复类型｜区域数量”。
- 选择列表项时，将该规则加载到右侧控件。
- 新增、保存、删除和移动均先调用 `SettingsController`；持久化成功后才刷新列表和选择位置。
- 校验或写盘失败时，错误显示在状态控件中，现有输入不清空。
- 关键词必须非空且唯一；至少选择一个区域；回复内容不能为空。
- 普通消息最多包含一个 `[图片=...]`，图片地址不可为空。
- 语音、视频和文件类型会取消并禁用两个频道复选框；切回普通消息或 Markdown 后重新启用。

## 生命周期

- `showSettingsWindow` 必须先取得 `currentKeywordStore()`；尚未初始化时显示错误并返回错误供 `onSettings` 记录日志。
- 重复点击设置只恢复并聚焦已有窗口，不创建第二个实例。
- 禁用时设置 closing 标志、发送 `WM_CLOSE` 并等待窗口线程退出。
- 即使禁用发生在窗口句柄创建前，窗口线程也必须在句柄发布后立即关闭。
- 不在 `DllMain` 或 Bee C 壳中创建窗口。

## 真实 Bee 验收清单

- [ ] 设置菜单打开窗口，标题和所有控件中文显示正常
- [ ] 窗口居中、置顶、固定尺寸，重复点击只有一个实例
- [ ] Tab/Shift+Tab 顺序稳定，多行回复框可输入换行
- [ ] 100%、125%、150% DPI 下无裁切、重叠或不可见按钮
- [ ] 新增、编辑、删除、上移、下移后立即写盘
- [ ] 校验错误显示在状态栏且不会清空输入
- [ ] 媒体类型禁用频道区域，切回文本后恢复
- [ ] 禁用会关闭窗口，卸载后 Bee 和 Worker 状态稳定

编译和自动测试不能替代上述原生窗口验收。
