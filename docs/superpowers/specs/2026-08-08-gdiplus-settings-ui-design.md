# GDI+ 现代扁平设置窗口设计

## 目标

将关键词回复设置窗口改为 A“清爽工作台”视觉方向：浅灰工作区、白色编辑表面、青绿色主操作、紧凑规则列表和清晰状态反馈。业务模型、保存语义、单实例、置顶、DPI 缩放、关闭等待和 Worker 生命周期保持不变。

## 技术边界

采用混合自绘，而不是重新实现完整文本编辑器：

- GDI+ 自绘窗口背景、分区、规则列表项、图标按钮、分段选择器、区域选项、状态栏和所有交互状态。
- 仅关键词单行输入和回复内容多行输入继续使用原生 Win32 `EDIT`，保留中文输入法、光标、选区、复制粘贴、滚动和辅助功能。
- 匹配模式改为两个 GDI+ 分段按钮；回复类型改为五个 GDI+ 选项；大小写和四个触发区域改为自绘复选项，不继续使用原生 `COMBOBOX`/`BUTTON`。
- 原生 `EDIT` 去除系统边框，由父窗口绘制输入表面、边框和焦点环；通过 `WM_CTLCOLOREDIT` 保持白色背景与统一文字色。

## 视觉系统

不使用渐变、玻璃效果、大面积阴影或装饰图形。圆角限制为 4～6px，间距使用 4/8px 体系。

| 语义 | 颜色 |
| --- | --- |
| 工作区背景 | `#F4F6F8` |
| 侧栏背景 | `#EEF2F3` |
| 主表面 | `#FFFFFF` |
| 边界 | `#D7DDDF` |
| 主文字 | `#202830` |
| 次文字 | `#68737D` |
| 主操作 | `#0F766E` |
| 主操作浅底 | `#E6F4F1` |
| 成功 | `#167A57` |
| 错误/删除 | `#B9384A` |
| 禁用文字 | `#9AA3AA` |

字体统一使用 `Microsoft YaHei UI`：窗口标题 18px/600，区域标题 13px/600，正文与输入 13px/400，辅助文字 12px/400。文字保持系统默认字距。

常规主题下正文和背景对比度至少满足 4.5:1。检测到 Windows 高对比度模式时，不强制上述品牌颜色，改用 `GetSysColor` 返回的窗口、文字、高亮和灰化颜色，确保自绘内容仍可辨认。

## 布局

保持 980×640 的 96 DPI 客户区，并按 DPI 等比缩放：

- 顶部 48px：窗口内容标题“关键词回复设置”和规则数量摘要。
- 左侧 300px：规则列表；顶部为“规则”与新增图标按钮，底部为删除、上移、下移图标按钮。
- 右侧：无外层卡片嵌套的编辑表单。关键词占整行；匹配模式与回复类型分组；大小写和四个区域使用自绘选择项；回复内容使用大尺寸多行输入。
- 底部 40px：左侧状态信息，右侧唯一主操作“保存”。

规则列表项显示关键词、匹配模式、回复类型和区域数量。选中项使用青绿色左侧指示条与浅色底；悬停只改变背景。无规则时显示“暂无规则”空状态和新增入口。

## 交互状态

- 所有可点击自绘元素提供 normal、hover、pressed、focused、disabled 五种状态。
- 焦点框使用 2px 青绿色描边，不能只依赖颜色变化表达焦点。
- 媒体回复类型会立即取消并禁用两个频道区域；禁用态降低对比并阻止点击。
- 保存成功在底部显示绿色文字；错误显示红色文字并保留用户输入。
- 删除属于危险操作，使用红色语义；仍沿用当前直接删除行为，不新增确认对话框。
- 不使用装饰动画。悬停和按下状态即时更新，避免 GDI+ 窗口中的输入延迟。

## 输入与键盘

- Tab/Shift+Tab 在规则列表、自绘操作、两个原生输入框和保存按钮之间按视觉顺序移动。
- 规则列表支持上下方向键切换，Enter 加载规则。
- 分段选择器支持左右方向键；复选项使用 Space 切换。
- 原生 `EDIT` 保持 IME、Ctrl+A/C/X/V/Z、多行回车和滚动行为。
- 自绘图标按钮提供工具提示文本：“新增”“删除”“上移”“下移”。

## 绘制与生命周期

- 设置窗口线程启动一次 GDI+，退出时释放 token、字体、画刷和其他句柄。
- `WM_PAINT` 使用兼容内存 DC 和位图完成双缓冲，再 `BitBlt` 到窗口，避免闪烁。
- `WM_ERASEBKGND` 返回 1；状态变化只调用 `InvalidateRect`，不在输入事件中直接绘制。
- `WM_SIZE`/DPI 变化重新计算纯布局结构和原生 `EDIT` 位置，固定客户区不允许控件重叠。
- 保留现有窗口创建失败、关闭竞态、宿主退出监视和设置仓库初始化处理。

## 测试与验收

自动测试覆盖纯布局和状态逻辑：96/120/144 DPI 尺寸、命中区域、分段/复选状态、媒体区域禁用、规则列表选择、按钮文案和布局不重叠。运行 `go test ./...`、`go vet ./...` 和 `build.bat KeywordReply.dll`。

真实 Bee 人工验收覆盖：GDI+ 非空绘制、无闪烁、所有 hover/pressed/focus/disabled 状态、中文 IME、复制粘贴、Tab/方向键、规则增删改排、100%/125%/150% DPI、单实例、置顶、禁用关闭和卸载稳定性。
